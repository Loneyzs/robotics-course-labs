# 机器人学实验

小组同步用仓库，包含指导书、Dobot SDK 示例和实验数据。

- `docs/`：参考资料、官方 SDK 和示例。
- `实验一/`：按指导书的四项实验分目录，`code/` 保存源码、配置、SDK 与 `records/` 原始记录，`results/` 保存截图、录像和图表，仅保留一个最新码垛日志 JSON。
- 缺失内容见 [实验一/缺失项提醒.md](实验一/缺失项提醒.md)。

首次下载：`git clone https://github.com/Loneyzs/robotics-course-labs.git`

更新前执行 `git pull`，新增数据后执行 `git add .`、`git commit -m "更新实验数据"`、`git push`。
