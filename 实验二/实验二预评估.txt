实验二预评估｜Dobot Magician 正逆解计算验证及单关节控制
记录时间 2026-11-24 17:06（UTC+08:00）
依据《实验一、二指导书》实验二第三至第五节。

一、实验内容与报告材料
1. 正解验证。按 D-H 模型推导各段和总计 5 个位姿变换矩阵。取八个空间象限各一个点，读取控制器位姿，根据 J1～J4 计算末端位姿，逐点对比。保存推导、Python 脚本、流程图、输出截图、记录表和误差分析。
2. 逆解验证。用几何关系推导逆解。可以复用同一批八象限数据，把同一帧 GetPose 的笛卡尔位姿代入逆解，再与该帧关节读数对比。保存公式推导、脚本、流程图、输出截图、记录表和误差分析。
3. 单关节搬运。读取当前位姿作为起点，给出中间点和终点，对各点求逆解。每段依次改变 J1、J2、J3，每条关节空间指令只改一个关节目标，其余关节目标保持在当前值。使用吸盘搬运校园卡。保存脚本、流程图、各点笛卡尔坐标和关节角，以及吸取、搬运、放下的照片或视频截帧。
4. 思考题涉及正解偏差来源、总变换矩阵各元素的物理含义、常用逆解方法及本实验选用几何法的原因。

二、已验证的接口与数据
Windows 识别到 USB-SERIAL CH340（COM7，VID:PID 1A86:7523）。Dobot USB 参数为 115200、8N1。直连串口和本地 64 位 SDK 均已读到真实的 GetPose、末端偏置和报警状态，结果一致。首次串口读帧超时，重新打开串口后稍等再发请求成功。
推荐复用 ../实验一/3.平面绘图操作/code/dobot_sdk.py 及同行目录下 sdk_x64 的 DobotDll.dll，已在本机 64 位 Python 3.11 验证。DobotStudio 安装目录自带的 DLL 为 32 位，导出函数参数与实验一封装所用 SDK 不同。按旧函数签名尝试调用时，测试进程退出。
控制器回报 XYZ = (131.2060, 0.0000, -9.5649) mm，R = 0.0000°。
J1～J4 = (0.0000, 12.9820, 73.7321, 0.0000)°。
配置的末端偏置 = (59.7000, 0.0000, 0.0000) mm，16 字节报警数据均为 0。偏置读数可用于核对控制器坐标定义，现场吸盘安装状态仍需目视确认。
位姿读取时 Y = 0。这组数据用于连接验证，八象限采样待正式执行。原始串口帧、校验和、SDK 读数及时间见 实验二连接验证.json。
本轮仅执行连接和读数验证，未发送运动、回零或吸盘控制指令。

三、执行可行性
脚本可以负责 D-H 正解和几何逆解、采数、误差计算、表格和流程图。通过 SDK 的关节空间 PTP 和吸盘接口可实现运动和搬运，控制链路的执行部分有待实机低速验证。
正式采样前需确认机械臂固定、扫掠范围净空和桌面高度，尤其是 X<0 区域及负 Z 姿态。图 3 的尺寸为大臂 135 mm、小臂 147 mm、腕部 59.7 mm。J3 按相对水平面的角度建模。
正式搬运时现场准备吸盘和校园卡，确认取放位置与桌面高度，并拍摄实物过程。采样点及运动可由 API 执行，现场净空和实物图像需结合目视确认。
